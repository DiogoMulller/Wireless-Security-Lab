# Wireless-Security-Lab
Laboratório prático de segurança de redes wireless desenvolvido durante meus estudos de Wireless Hacking.

O objetivo deste projeto é documentar a reprodução de diferentes cenários de segurança e ataque contra redes Wi-Fi em um ambiente de laboratório controlado e autorizado.

## Objetivos

* Compreender o funcionamento das principais tecnologias de segurança Wi-Fi.
* Praticar reconhecimento e enumeração de redes wireless.
* Analisar mecanismos de autenticação e criptografia.
* Reproduzir ataques contra redes vulneráveis em ambiente controlado.
* Analisar tráfego de rede utilizando Wireshark.
* Praticar reconhecimento de dispositivos utilizando Nmap.
* Documentar vulnerabilidades e evidências.
* Desenvolver metodologia para elaboração de relatórios de pentest wireless.
* Ambiente
* Kali Linux
* Docker / Docker Compose
* Ferramentas de segurança wireless
* Wireshark
* Nmap
* Routersploit
* Ambiente de laboratório isolado
